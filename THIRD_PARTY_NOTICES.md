# Third-party notices

ChatToCodex was designed after studying the MIT-licensed **Chat On Steroids** project (`tote c448-spec/chat-on-steroids` in the local reference checkout). Its separation of a loopback MCP server from an OpenAI Secure MCP Tunnel adapter informed this project's architecture.

This first ChatToCodex MVP was implemented as a new Node-only codebase rather than copied wholesale from the Electron application. Before public distribution, any subsequently copied or adapted upstream source must carry the upstream copyright and MIT permission notice required by its license.

Runtime dependencies retain their own licenses as distributed by npm.
